# DeliveryOps AI

배송 예외 분석 및 운영자 승인 기반 조사 요청 에이전트를 만드는 Java/Spring 백엔드 개인 포트폴리오 프로젝트입니다.

## 목표

- LLM의 조회 Tool Calling과 기존 업무 로직을 안전하게 연결합니다.
- 고객 주장, 확인된 배송 사실, 미확인 원인을 구분합니다.
- 서버가 근거와 업무 조건을 검증하고, 운영자의 별도 승인 후 조사 티켓을 생성합니다.
- 권한, 트랜잭션, 동시성, 중복 방지와 실패 처리를 검증합니다.

## 개발 방향

단일 애플리케이션과 단일 PostgreSQL DB로 시작하며, 독립적으로 만든 합성 배송 데이터만 사용합니다.

변경은 작은 PR 단위로 구현하고 검증한 뒤 검토합니다. 이 초기 커밋에는 저장소 소개와 Git 제외 설정만 포함합니다.

## 진행 단계

- 범위·업무 규칙·기술 버전 검토
- 프로젝트 뼈대와 로컬 DB
- 배송 모델·마이그레이션·합성 데이터
- 조회 API·최소 권한·테스트
- LLM 조회 Tool 연동
- 구조화 제안과 검증
- 승인·티켓·중복 방지
- 평가와 문서화
